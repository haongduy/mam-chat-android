MÂM Chat is a fork of Element X Android for the Matrix homeserver https://chat.mam.info.vn.

Sign in with an existing account using password login (m.login.password). Public registration is disabled. This build does not include a custom Firebase project, so push notifications are not provided. Calling (TURN, LiveKit, MatrixRTC) and QR / Matrix Authentication Service login are not configured and should not be treated as working.

The app is free software under the GNU Affero General Public License version 3, the same license as Element X Android, with Element's alternative commercial license also preserved. It is not the official Element app and installs separately (application id vn.info.mam.chat).
